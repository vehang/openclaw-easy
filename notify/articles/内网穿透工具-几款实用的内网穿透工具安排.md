## 0x01 NPS-NPC：轻量级选手的福音

### 1.1 闪亮登场

NPS 是一款轻量级、高性能、功能强大的内网穿透代理服务器。它就像个万能插座，支持 TCP、UDP 流量转发，各种上层协议通吃（访问内网网站、本地支付接口调试、SSH 访问、远程桌面、内网 DNS 解析...）。还支持内网 HTTP 代理、内网 SOCKS5 代理、P2P 等，自带功能强大的 Web 管理端。

简单来说，你需要：

- 一台有公网 IP 的服务器（VPS），运行服务端（NPS）。
- 一个或多个运行在内网的服务器或者 PC，运行客户端（NPC）。

### 1.2 技能点

- Go 语言编写：性能杠杠的！
- 跨平台：Windows、Linux、macOS 全家桶伺候！
- 多种协议代理：TCP、UDP、HTTP、SOCKS5...
- Web 管理端：图形化界面，操作简单易上手！

### 1.3 使用姿势

**NPS（服务端）安装配置：**

```bash
cd ~
wget https://github.com/cnlh/nps/releases/download/v0.23.2/linux_amd64_server.tar.gz
tar xzvf linux_amd64_server.tar.gz
cd ~/nps
vim conf/nps.conf
```

修改 `#web` 下面的参数：

```
web_host= 服务器IP或者域名
web_username= admin（登录用户名）
web_password= 你的密码
web_port=8080（web管理端口）
```

如果服务器只有部分端口（比如 80、443）可以出网，修改 `#bridge` 把 NPC 连接端口改成出网端口：

```
bridge_type=tcp
bridge_port=443
bridge_ip=0.0.0.0
```

启动：

```bash
# Mac/Linux
./nps test|start|stop|restart|status
# Windows
nps.exe test|start|stop|restart|status
```

**NPC（客户端）：**

```bash
./npc -server=你的IP:8024 -vkey=唯一验证密码 -type=tcp
```

在 Web 管理端，可以通过"新增"方式添加客户端连接，每个连接的 vkey 都是唯一的。每个客户端连接建立后，都可以创建多个不同协议的隧道，通过不同的协议和端口连接到代理的内网机器。

## 0x02 FRP：高性能反向代理的代表

### 2.1 闪亮登场

FRP (Fast Reverse Proxy) 是一款专注于内网穿透的高性能反向代理应用，支持 TCP、UDP、HTTP、HTTPS 等多种协议。它可以将内网服务以安全、便捷的方式，通过具有公网 IP 节点的中转暴露到公网。

### 2.2 技能点

- 客户端服务端通信支持 TCP、KCP 以及 WebSocket 等多种协议。
- 端口复用：多个服务通过同一个服务端端口暴露。
- 跨平台：支持 Windows、Linux、macOS。
- 多种插件：提供很多实用功能。

### 2.3 使用姿势

下载地址：https://github.com/fatedier/frp/releases

**1. 通过 RDP 访问家里的机器**

`frps.ini`（服务端）：

```ini
[common]
bind_port = 7000
# 用于身份验证，请自行修改，要保证服务端与客户端一致
token = abcdefgh
```

启动：`./frps -c ./frps.ini`

`frpc.ini`（客户端，假设 frps 公网 IP 为 x.x.x.x）：

```ini
[common]
server_addr = x.x.x.x
server_port = 7000
token = abcdefgh

[rdp]
type = tcp
local_ip = 127.0.0.1
local_port = 3389
remote_port = 6000
```

启动：`./frpc -c ./frpc.ini`

通过 RDP 访问：`x.x.x.x:6000`

开机自启（Windows）：在 frpc.exe 同级目录创建 `start_frpc.vbs`：

```vbs
CreateObject("WScript.Shell").Run """D:\Program Files\frp_windows_amd64\frpc.exe""" & " -c" & """D:\Program Files\frp_windows_amd64\frpc.ini""",0
```

复制到 `C:\Users\<USER_NAME>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`，粘贴为快捷方式即可。

**2. 通过 SSH 访问公司内网机器**

```ini
[ssh]
type = tcp
local_ip = 127.0.0.1
local_port = 22
remote_port = 6000
```

访问：`ssh -oPort=6000 test@x.x.x.x`

**3. 通过自定义域名访问部署于内网的 Web 服务**

`frps.ini` 加 `vhost_http_port = 8080`；`frpc.ini`：

```ini
[web]
type = http
local_port = 80
custom_domains = www.yourdomain.com
```

域名 A 记录解析到 x.x.x.x，浏览器访问 `http://www.yourdomain.com:8080`。

**4. 对外提供简单的文件访问服务**

```ini
[test_static_file]
type = tcp
remote_port = 6000
plugin = static_file
plugin_local_path = /tmp/file
plugin_strip_prefix = static
plugin_http_user = abc
plugin_http_passwd = abc
```

访问 `http://x.x.x.x:6000/static/` 查看文件。

**高级玩法：**

- 统计面板：`frps.ini` 中配置 `dashboard_port = 7500`、`dashboard_user/pwd`（默认 admin）
- 加密与压缩：代理配置加 `use_encryption = true` / `use_compression = true`
- TLS：common 中 `tls_enable = true`
- 代理限速：`bandwidth_limit = 1MB`
- 范围端口映射：

```ini
[range:test_tcp]
type = tcp
local_ip = 127.0.0.1
local_port = 6000-6006,6007
remote_port = 6000-6006,6007
```

## 0x03 EW：短小精悍的老牌劲旅

### 3.1 闪亮登场

EW (EarthWorm) 是一套便携式的网络穿透工具，具有 SOCKS v5 服务架设和端口转发两大核心功能，可在复杂网络环境下完成网络穿透。虽然工具已停止更新，但依然经典！

### 3.2 技能点

- 轻量级：C 语言编写，体积小巧。
- 多级代理：支持设置多级代理。
- 跨平台：支持 Windows、Linux、macOS。
- SOCKS5 代理：只支持 SOCKS5 代理。

### 3.3 使用姿势

官网：http://rootkiter.com/EarthWorm/

（如无特殊说明代理端口均为 1080，服务均为 SOCKSv5）

EW 共有 6 种命令格式：`ssocksd`、`rcsocks`、`rssocks`、`lcx_slave`、`lcx_listen`、`lcx_tran`。

**1. 正向 SOCKS v5 服务器**

```bash
./ew -s ssocksd -l 1080
```

**2. 反弹 SOCKS v5 服务器**

```bash
# a) 公网主机 A 上运行：
./ew -s rcsocks -l 1080 -e 8888
# b) 目标主机 B 上启动 SOCKS v5 服务并反弹到公网 8888 端口：
./ew -s rssocks -d 1.1.1.1 -e 8888
```

**3. 多级级联**

```bash
./ew -s lcx_listen -l 1080 -e 8888
./ew -s lcx_tran -l 1080 -f 2.2.2.3 -g 9999
./ew -s lcx_slave -d 1.1.1.1 -e 8888 -f 2.2.2.3 -g 9999
```

三级级联示例：

```bash
./ew -s rcsocks -l 1080 -e 8888
./ew -s lcx_slave -d 127.0.0.1 -e 8888 -f 127.0.0.1 -g 9999
./ew -s lcx_listen -l 9999 -e 7777
./ew -s rssocks -d 127.0.0.1 -e 7777
```

数据流向：SOCKS v5 -> 1080 -> 8888 -> 9999 -> 7777 -> rssocks

## 0x04 Ngrok：官方出品，稳定可靠

### 4.1 闪亮登场

Ngrok 是一个反向代理，通过在公共端点和本地运行的 Web 服务器之间建立一个安全的通道，实现内网主机的服务暴露给外网。Ngrok 可捕获和分析所有通道上的流量，便于后期分析和重放，方便协助服务端程序测试。

### 4.2 技能点

- 官方维护：稳定性有保障。
- 跨平台：支持 Windows、Linux、macOS。
- 流量记录和重发：方便调试和分析。

### 4.3 使用姿势

1. 进入官网 https://ngrok.com/ 注册账号并下载
2. 运行授权命令：

```bash
./ngrok authtoken 1hAotxhmORtzCYvUc3BsxDBPh1H_****
```

3. `./ngrok http 80` 即可将机器的 80 端口 HTTP 服务暴露到公网，并提供一个公网域名。

其他命令：

```bash
# 有授权的设置文件共享
ngrok http -auth="user:password" file:///Users/alan/share
# 无授权的设置文件共享
ngrok http "file:///C:\Users\alan\Public Folder"
# 将主机的 3389 的 TCP 端口暴露到公网
ngrok tcp 3389
```
